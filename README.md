# MF
Management Framework available under an Attribution-ShareAlike 4.0 International license.

The Management Framework repository has two main files:

The first document is the Management Framework (Management_Framework.md).
This is the main document. It describes what Management is about using the
concept of a through a "Management Profile" which explains the key aspects of a
Venture like a company and how those aspects require the application of the
concept of Management. 

The second document (Management_Framework-Appendix.md) has specific Management
Tools that can aid a Manager in achieving results efficiently.

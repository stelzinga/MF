# MF

This Management Framework repository in GitHub has two essential  files:

The first document is the Management Framework (Management_Framework.md). This is the main document. It describes what Management is about using the concept of a "Management Profile" which explains the key aspects of a Venture like a company, and it explains how those aspects require the application of Management. Key words used in this document are: Operations, Processes (Run, Change), Resources (Staff, Assets, Liabilties), Capital (Equity, Liabilities), Results (Revenue. Cost, Risk Image), Management (Planning, Organising, Leading, Controlling, Business Functions, Tools, Management Cycle).   
Each of these keywords are part of the Profile and are explained in detail in
the main document. 

The second document (Management_Framework-Appendix.md) has specific Management
Tools that can aid a Manager in achieving results efficiently. Examples of such
Tools are: Eisenhower Matrix, SWOT, SMART, Obective Notation, COM, TOM, Project
Management, Business Continuity Management, Mentoring, Coaching, BOD, Root
Cause Analysis, BuJo, etc., etc.
The tools provided are sometimes public domain, sometimes they are from the
author based on experience.

In addition to the two documents, the repo also offers a downloadable Excel
file that has various embedded tools that help a Manager in daily work.
